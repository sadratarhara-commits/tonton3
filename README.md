## ✨ ویژگی‌های وب‌سایت

- 💎 **طراحی لوکس Soft Minimal Luxury**: منطبق دقیق با دیزاین سیستم گوگل استیچ و اصول تایپوگرافی راست‌به‌چپ (RTL) با فونت چشم‌نواز **وزیرمتن** و **Noto Serif**.
- 👗 **صفحه اصلی جامع (Home Page)**:
  - بنر هیرو با تصاویر ادیتوریال و برچسب‌های شناور اصالت پارچه
  - گرید دسته‌بندی‌های برگزیده (ست‌های دانتل، لباس خواب ابریشمی، لباس زیر ارگانیک، گن نامرئی)
  - ویترین پرفروش‌ترین‌ها با فیلتر موضوعی، سوئیچ رنگ و دکمه افزودن سریع به سبد
  - ارزش‌های ۴ گانه برند (بسته‌بندی ۱۰۰٪ محرمانه، استاندارد OEKO-TEX، مشاوره تخصصی، تعویض آسان)
  - بخش نظرات و رضایت خریداران همراه با ستاره‌های امتیازدهی
  - بنر کتابچه استایل و لوک‌بوک فصلی لیندا
- 📏 **راهنمای هوشمند تعیین سایز سوتین (Smart Bra Size Calculator)**:
  - اسلایدر اندازه‌گیری دور زیر سینه (۶۵ تا ۹۵ سانتی‌متر)
  - انتخاب کاپ (A, B, C, D) با محاسبه بلادرنگ و پیشنهاد سایز استاندارد اروپایی (EU)
- 🛍️ **صفحه اختصاصی کالا (Product Detail - ست دانتل والنتینا)**:
  - گالری تصاویر چندگانه با ریل تصاویر بندانگشتی و بزرگنمایی
  - پاپ‌آپ ویدیوی آنباکسینگ و بررسی بسته‌بندی محرمانه
  - انتخابگر پالت‌های رنگی و چیپ‌های سایزبندی
  - هشدار هوشمند موجودی انبار
  - ۴ تب تخصصی: توضیحات و ویژگی‌ها، جدول کامل اندازه‌ها، دستورالعمل شست‌وشو، و نظرات خریداران
  - امکان ثبت نظر جدید توسط کاربر با فرم تعاملی و ثبت فوری
  - بخش «ست‌ها و مکمل‌های پیشنهادی» (Cross-sell) با دکمه‌های افزودن مستقیم
  - نوار خرید چسبان پایین صفحه (Sticky Purchase Bar) هنگام اسکرول
- 🛒 **سبد خرید کشویی تعاملی (Cart Drawer)**:
  - نوار پیشرفت ارسال رایگان
  - کنترل افزایش/کاهش تعداد و حذف کالا
  - فرم اعمال کوپن و کد تخفیف (مثال: `LINDA10` یا `VIP15`)
- 💳 **فرم تسویه‌حساب و ثبت نهایی (Checkout Modal)**:
  - دریافت اطلاعات گیرنده، آدرس و انتخاب روش ارسال (پیک تهران / پست ویژه)
  - تضمین بسته‌بندی محرمانه و تولید کد پیگیری اختصاصی
- 🔍 **مودال جستجوی سریع و لیست علاقه‌مندی‌ها (Wishlist)**

## 🚀 راهنمای گام‌به‌گام برای قرار دادن در گیت‌هاب (GitHub)

برای اینکه این پروژه را در اکانت گیت‌هاب خودتان قرار دهید و آن را آنلاین کنید، این مراحل ساده را طی کنید:

### گام ۱: ساخت ریپازیتوری در گیت‌هاب
1. وارد سایت [GitHub.com](https://github.com) شوید.
2. روی دکمه‌ی سبز رنگ **New** یا علامت `+` در بالا کلیک کنید تا یک مخزن (Repository) جدید بسازید.
3. نام آن را مثلاً `lynda-lingerie` بگذارید.
4. آن را روی **Public** قرار دهید و تیک گزینه‌های "Add a README" را نزنید (چون فایل‌ها آماده هستند).
5. دکمه **Create repository** را بزنید.

### گام ۲: ارسال فایل‌ها به گیت‌هاب (Push)
ترمینال سیستم خود را در پوشه پروژه باز کنید و دستورات زیر را وارد نمایید:

```bash
# ۱. راه‌اندازی گیت
git init

# ۲. افزودن تمام فایل‌های پروژه
git add .

# ۳. ثبت کامیت اولیه
git commit -m "feat: initial commit of Lynda Lingerie luxury store"

# ۴. نام‌گذاری برنچ اصلی به main
git branch -M main

# ۵. متصل کردن به ریپازیتوری شما (نام کاربری خود را جایگزین کنید)
git remote add origin https://github.com/YOUR_USERNAME/lynda-lingerie.git

# ۶. ارسال به گیت‌هاب
git push -u origin main
```

## 🌐 انتشار و هاست رایگان در اینترنت

### روش ۱: استفاده از GitHub Pages (خودکار با GitHub Actions)
فایل آماده گردش‌کار در مسیر `.github/workflows/deploy.yml` قرار داده شده است:
1. در صفحه ریپازیتوری گیت‌هاب خود به تب **Settings** بروید.
2. از منوی سمت چپ روی **Pages** کلیک کنید.
3. در قسمت **Build and deployment**، گزینه **Source** را از `Deploy from a branch` به **GitHub Actions** تغییر دهید.
4. با اولین Push، سایت شما به آدرس زیر منتشر می‌شود:
   `https://YOUR_USERNAME.github.io/lynda-lingerie/`

### روش ۲: انتشار ۱-کلیکی روی Vercel (سریع‌ترین راه)
1. به سایت [Vercel.com](https://vercel.com) بروید و با اکانت گیت‌هاب خود وارد شوید.
2. دکمه **Add New Project** را بزنید و ریپازیتوری `lynda-lingerie` را انتخاب کنید.
3. بدون نیاز به تغییر تنظیمات، دکمه **Deploy** را بزنید. ظرف کمتر از ۱ دقیقه لینک اختصاصی پرسرعت دریافت خواهید کرد.
